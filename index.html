AltCheck Fixtures Directory

This static HTTPS fixtures site hosts stable, deterministic HTML and non-HTML documents used to verify the AltCheck consensus ledger on GenLayer Studionet (Preview).

  • good.html (Fully accessible, target Grade A/B)
  • bad.html (Defective across WCAG R1-R12, target low grade)
  • mixed.html (Calibrated clear and vague descriptions for intelligent model layer)
  • fixed.html (Remediated version of bad.html)
  • shell.html (Client-rendered SPA shell, triggers SHELL_ONLY mode)
  • demo.html (Live remediation before/after demonstration page)
  • data.json (Non-HTML JSON test fixture)
  • notes.txt (Non-HTML text test fixture)
